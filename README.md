#  Personal Portfolio Website

This is my personal responsive portfolio website built using **HTML, CSS, and JavaScript**.  
It showcases my skills, projects, and contact information in a clean and modern UI.

---

##  Live Demo
👉 https://divy686.github.io/my-portfolio-website/

---

##  Features

- Responsive design for all devices 
- Smooth navigation between sections
- Clean and modern UI design
- Home, Skills, Projects, Contact sections
- Project showcase section
- Contact links (Email, GitHub, LinkedIn)

---

##  Technologies Used

- HTML5
- CSS3
- JavaScript (basic)
- Flexbox / Responsive Design

---


---

##  Deployment

This project is deployed using **GitHub Pages**.

Steps used:
- Uploaded code to GitHub repository
- Enabled GitHub Pages from `main` branch
- Live site generated automatically
